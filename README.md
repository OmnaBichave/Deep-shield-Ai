# Deep Shield AI

A dark, minimal, **offline** browser prototype that shows simple *manipulation indicators* for images and short videos.

> **Educational prototype. Not forensic proof.** Not for legal or evidentiary decisions. Results may be wrong.
> Simple heuristics cannot reliably detect modern AI-generated media or deepfakes, and no detection accuracy is claimed.

## Features

- Upload a JPEG, PNG or WebP image, or a short MP4 / WebM video (drag and drop, or tap to choose; max 15 MB).
- Videos: 8 evenly spaced frames are sampled through a canvas and the results averaged.
- Five signals, all in plain JavaScript with the Canvas API:
  1. Error Level Analysis (fixed-quality JPEG re-encode, compare residuals)
  2. Noise consistency across 16 px blocks
  3. Frequency / sharpness anomalies (Laplacian variance and an 8x8 DCT high-frequency check)
  4. Edge and blur discontinuities
  5. Metadata presence check (basic EXIF / PNG text / WebP read, in memory only)
- A 0-100 score, a per-signal bar breakdown and plain-language explanations.
- Verdicts: **Few Indicators**, **Inconclusive**, **Multiple Indicators**. Conflicting signals give Inconclusive.
- A heatmap overlay marking unusual regions (can be toggled off).
- Friendly errors for wrong file types, files over 15 MB, corrupt media, undecodable video and tiny images.
- Three test images generated by code (clean gradient, uniform noise, patched noise region), so the app can be tried without any real photo.
- Detection only. The code never generates, swaps or edits faces or images.

## Privacy

Files are processed locally in your browser and never leave your device. The page makes no network requests, uses no cookies, analytics, trackers, CDNs or external fonts, and stores nothing. A Content Security Policy meta tag blocks network connections as a second safeguard. It works fully offline.

## Run locally

No build step and nothing to install. Download or clone the folder and open `index.html` in a modern browser (Chrome, Edge, Firefox, Safari).

## Deploy to GitHub Pages

1. Create a new public repository on GitHub (for example `deep-shield-ai`).
2. Upload the contents of this folder to the repository root, so `index.html` sits at the top level. (Unzip first; GitHub does not unpack ZIP files for you.)
3. Open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and the `/ (root)` folder, then save.
5. After a minute or two the site appears at `your-username.github.io/deep-shield-ai`.

All paths in the project are relative, so it works from a sub-path.

## Limitations

- Normal editing, filters, resizing, screenshots and social-media re-compression can raise indicators on genuine media.
- Images are shrunk to at most 640 px on the longer side before analysis, which weakens some signals.
- Missing metadata is common and only a weak hint; present metadata can be forged.
- Do not use results to accuse anyone or to decide legal, employment or safety matters.
