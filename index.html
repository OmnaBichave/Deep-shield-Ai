    How it works

    All five checks use only the browser's Canvas API. Large inputs are shrunk so the longer side is at most 640 px. Videos are sampled at 8 evenly spaced frames and the results averaged.

    • Error Level Analysis: re-saves the image as JPEG at a fixed quality and looks for regions that change more or less than the rest.
    • Noise consistency: estimates grain level per 16 px block and flags blocks that differ from the typical level.
    • Frequency / sharpness: compares Laplacian sharpness and 8x8 DCT high-frequency energy between blocks.
    • Edge and blur continuity: looks for sudden sharpness jumps between neighbouring areas.
    • Metadata check: reads basic EXIF, PNG text and WebP fields in memory. Missing metadata is common and only a weak hint.

    The signals are combined into a 0-100 score. Verdicts are Few Indicators, Inconclusive or Multiple Indicators. When signals disagree the result is Inconclusive.

    Limitations

    • These simple heuristics cannot reliably detect modern AI-generated images or deepfakes. No accuracy is claimed.
    • Normal edits, filters, resizing, social-media re-compression and screenshots can all trigger indicators.
    • Genuine, untouched media can score high; manipulated media can score low.
    • The tool only detects. It never creates or edits faces or images.
    • Do not use results to accuse anyone or to decide legal, employment or safety matters.

    Privacy

    • Files are read and analyzed locally. Nothing is uploaded.
    • This page makes no network requests and has no analytics, cookies, trackers or stored data.
    • It works fully offline. Closing or resetting the page discards the file from memory.
